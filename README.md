# 💻 GeniusIdiot

💡 Шуточная программа **«Гений-Идиот»** для оценки интеллектуальных способностей. Пользователю задаётся серия вопросов, приложение считает количество правильных ответов и выводит соответствующий “диагноз”.

Проект сделан в процессе изучения **C#**, **ООП**, **Windows Forms** и работы с **файлами (CSV)**.

---

## 📄 Описание

- По умолчанию доступно **5 вопросов** (можно расширять).
- Программа анализирует количество правильных ответов и выводит соответствующий **диагноз**.
- Реализовано в **двух вариантах**:

  I) **Console** приложение  
  II) **WinForms** приложение

---

## 📦 Версии приложения

### ✅ GeniusIdiotConsoleApp
Консольная версия с меню:
- запуск викторины;
- просмотр списка вопросов;
- добавление/удаление вопросов;
- просмотр результатов (последние 10).

---

### ✅ GeniusIdiotWinFormsApp
Версия на Windows Forms:
- форма входа / главное меню;
- форма викторины;
- форма добавление/удаление вопросов;
- вывод результатов (последние 10 результатов через `MessageBox`).

---

## 🗂️ Хранение данных

### Вопросы (CSV)

Вопросы и результаты хранятся в файле:

- **Windows:**  
  `%LOCALAPPDATA%\GeniusIdiot\questions.csv`<br>
  `%LOCALAPPDATA%\GeniusIdiot\userResult`

Файлы создаётся автоматически при первом запуске:
- создаётся каталог `%LOCALAPPDATA%\GeniusIdiot`
- создаётся файл `questions.csv`
- создаётся файл `userResult`
- затем вопросы загружаются из файла
